# FinBridge Copilot Prompting Starter Guide (For End-Users)

**Audience:** Non-technical office staff  
**Tools:** Microsoft 365 Copilot in Outlook, Word, and Excel  
**Date:** 2026-08-12

This guide is built to help you get useful results quickly, without needing technical language.

---

## Start here: a simple prompt formula

Use this 4-part formula whenever you are not sure how to phrase a prompt:

**Task + Context + Output + Tone**

- **Task:** What you want Copilot to do
- **Context:** What it should use (email thread, document, table, meeting notes)
- **Output:** The format you want back (bullet list, draft email, table, action list)
- **Tone:** How it should sound (friendly, concise, formal, neutral)

### Memory trick
Think: **"Do, Use, Return, Sound"**

- **Do:** action
- **Use:** source
- **Return:** format
- **Sound:** style

### Quick reusable template
"Please **[task]** using **[context]**. Return it as **[output format]**. Keep the tone **[tone]**."

Example:
"Please summarise this email thread using the last 8 messages. Return it as 5 bullet points plus 3 actions. Keep the tone neutral and clear."

## Outlook prompt examples (real day-to-day use)

### 1) Turn a long thread into actions
"Summarise this email thread into: 1) key decisions, 2) open questions, and 3) actions with owner names and due dates if they are mentioned. Keep it under 12 bullets."

### 2) Draft a polite follow-up
"Draft a follow-up email to [person's name] about the invoice approval request from last Thursday. Mention that the payment run closes tomorrow at 3:00 PM. Keep it polite, concise, and professional."

### 3) Prepare me before I reply
"Before I reply, give me a short brief: what the sender is asking, any risks if we miss deadlines, and a suggested response I can send in under 120 words."

Tip: If Copilot is too generic, add one extra instruction like "include dates mentioned in the thread" or "keep this under 8 lines."

---

## Word prompt examples (documents, notes, and drafts)

### 1) Create a clear first draft
"Using my notes in this document, draft a one-page project update for leadership with these sections: Status, Risks, Decisions Needed, and Next Steps. Keep it plain English and avoid jargon."

### 2) Improve readability without changing meaning
"Rewrite this draft so it is easier for non-technical readers. Keep all facts the same, shorten long sentences, and use headings and bullet points where helpful."

### 3) Build a meeting summary from rough notes
"Turn these meeting notes into a clean summary with: key points, decisions made, and action items with suggested owners. End with a short section called 'What to confirm next meeting'."

Tip: If you need a specific length, ask directly: "Keep this to around 300 words" or "fit this on one page."

---

## Excel prompt examples (tables, trends, and checks)

### 1) Explain what changed month to month
"From this table, identify the top 5 biggest changes from one month to the next, show whether each went up or down, and give a one-line plain-English explanation for each."

### 2) Clean up and standardise data
"Review this sheet and list data quality issues such as missing values, inconsistent date formats, duplicate rows, and unusual numbers that look very different from the rest. Return a table with columns: Issue Type, Where It Is, Why It Matters, Suggested Fix."

### 3) Build a manager-ready summary
"Create a short performance summary from this data for a weekly team check-in: 3 highlights, 3 concerns, and 3 actions we should take next week. Keep it concise and business-friendly."

Tip: Ask for output format explicitly, for example: "Return this as a table I can paste into email."

## Make prompts better in 10 seconds

If the first result is not right, do not start over. Refine it:

- "Make this shorter and more direct."
- "Use a friendlier tone."
- "Add due dates and owners."
- "Focus only on finance-related points."
- "Give me 2 alternative versions."

Small refinements usually produce much better results than a totally new prompt.

## Data safety reminder (FinBridge Day 1 habit)

From Day 1, we use a simple habit: **pause and check data sensitivity before prompting**.

- Use Microsoft 365 Copilot for work content in FinBridge tools like Outlook, Word, Excel, Teams, SharePoint, and OneDrive.
- **Do not paste confidential client data into external AI tools** (public chatbots or unapproved AI websites/apps).
- If in doubt, remove client identifiers and sensitive details, or ask your manager or security contact before sharing.

This is a safety habit, not a reason to avoid Copilot. You should still use Copilot for everyday work in approved FinBridge systems.

A good rule: if you would not post it in a public place, do not paste it into an external AI tool.

## One-page cheat sheet

Use this line whenever you are stuck:

"Please [task] using [context]. Return as [format]. Keep the tone [style]."

Then refine with one extra instruction:

- "Keep it under 8 bullets"
- "Use plain English"
- "Include actions, owners, and dates"

That is enough to get strong results in most everyday Outlook, Word, and Excel tasks.
