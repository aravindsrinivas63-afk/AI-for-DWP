# Copilot Support Tickets: End-User Communications

Date: 2026-08-12
Audience: End users reporting Copilot issues

## 1) Finance lead - Copilot will not summarise Q3 board pack in SharePoint

Plain English explanation:
You can see the board pack in SharePoint, but Copilot may not have the same level of access to that exact file in the way it needs for summarising.

Next possible steps:
1. We will check your direct access on the specific board-pack file (not only site-level visibility).
2. We will confirm whether any file protection or sensitivity settings limit Copilot use.
3. If access and policy look correct, we will re-test after confirming indexing has completed.

What you can do now:
Open the file directly from SharePoint and share the exact file link with IT so we can validate the precise permission path.

## 2) New hire - Copilot in Outlook does not know recent emails

Plain English explanation:
Because your account is very new, Copilot may not have finished indexing your mailbox content yet.

Next possible steps:
1. We will confirm your Copilot license assignment time and mailbox readiness.
2. We will check whether your Outlook client is signed into the correct work account.
3. We will re-test once indexing time has passed.

What you can do now:
Stay signed into your work account in Outlook and try again later the same day.

## 3) HR manager - Copilot in Word says it cannot access a sensitive salary file

Plain English explanation:
This usually means security controls are working as designed. Sensitive files can be restricted from Copilot or from cross-app access.

Next possible steps:
1. We will review the spreadsheet sensitivity label and policy settings.
2. We will confirm whether your permissions include the required rights for Copilot processing.
3. If policy allows it, we will test with an approved secure method.

What you can do now:
Send IT the file location and the exact error message so we can verify policy and permissions quickly.

## 4) Sales rep - Copilot in Teams cannot find contract shared by guest link from another org

Plain English explanation:
Content shared through external guest links from another organization is often outside what your tenant Copilot can use for grounding.

Next possible steps:
1. We will confirm this is an external cross-tenant guest-link scenario.
2. We will check whether there is an internal tenant copy that Copilot can access.
3. We will advise a supported sharing route if needed.

What you can do now:
Ask the sender for an approved internal copy or a sharing method supported inside your tenant.

## 5) IT admin - Copilot stopped for whole Finance team this morning

Plain English explanation:
A sudden team-wide issue is most often caused by a licensing, client, or tenant configuration change, not by an individual user action.

Next possible steps:
1. We will check Copilot license status for affected users.
2. We will review recent policy or configuration changes.
3. We will check Microsoft 365 service health and then escalate only if required.

What you can do now:
Share a quick list of affected users, their app versions, and first failure time so we can narrow the scope fast.

## 6) Manager - Copilot summarised a file the manager forgot they could access

Plain English explanation:
Copilot can use files you are allowed to access, even if you have not opened them recently or forgot that access was granted.

Next possible steps:
1. We will confirm your effective access on that folder/file.
2. We will review whether that access is still needed for your role.
3. If not needed, we will request access cleanup through the data owner.

What you can do now:
Tell us if you want that access removed so we can raise an access review request.

## 7) Analyst - Copilot gives generic answers and ignores internal SharePoint content

Plain English explanation:
Generic answers usually mean Copilot is not fully connected to your internal work context, often due to account, client, or licensing setup.

Next possible steps:
1. We will verify your Copilot license and app support status.
2. We will confirm you are signed into the correct tenant account.
3. We will test retrieval from a known internal SharePoint file you can access.

What you can do now:
Share one internal SharePoint file link you can open, plus a sample prompt you used, so we can reproduce.

## 8) Executive assistant - Copilot in Outlook cannot see shared mailbox calendar

Plain English explanation:
Even when you manage a shared mailbox, Copilot support can depend on delegate permissions and feature scope for shared mailbox data.

Next possible steps:
1. We will validate your delegate permissions on the shared calendar.
2. We will confirm current Copilot support behavior for shared mailbox calendar scenarios.
3. We will provide a supported workaround if direct grounding is limited.

What you can do now:
Send IT the shared mailbox address and a screenshot of your calendar permissions so we can verify quickly.

## Closing note for end users

Most Copilot issues are resolved by access, policy, client, or indexing checks. We treat product defects as a last step after those checks are completed.
