# Copilot Support Ticket Triage (Likely Cause First)

Date: 2026-08-12  
Role lens: DWP engineer training Copilot support tickets

## Ticket-by-ticket assessment

| ID | Ticket | Likely cause (ranked, most probable first) | Fastest check (single first check) | Is this actually a Copilot bug? |
|---|---|---|---|---|
| 1 | Finance lead: Copilot won’t summarise the Q3 board pack in SharePoint. “It’s right there, I can see it myself.” | 1) permissions/access boundary 2) sensitivity label restriction 3) data indexing lag 4) license/client prerequisite issue 5) guest/external sharing limitation 6) genuine Copilot fault | In SharePoint, confirm whether the exact board-pack file is in the user’s direct ACL (not just visible via broad site navigation). | **No**. Seeing a file in SharePoint UI does not always mean Copilot has equivalent retrieval rights to that specific content path/context. Access scoping is the most likely cause. |
| 2 | New hire (started yesterday): Copilot in Outlook seems to know nothing about my recent emails. | 1) data indexing lag 2) license/client prerequisite issue 3) permissions/access boundary 4) sensitivity label restriction 5) guest/external sharing limitation 6) genuine Copilot fault | Check account start/license assignment timestamp versus expected Copilot indexing propagation window. | **No**. New-hire timing strongly points to indexing latency or recent enablement rather than a product fault. |
| 3 | HR manager: Asked Copilot in Word to pull data from a sensitive salary review spreadsheet, got “I don’t have access to that content.” | 1) sensitivity label restriction 2) permissions/access boundary 3) data indexing lag 4) license/client prerequisite issue 5) guest/external sharing limitation 6) genuine Copilot fault | Open the spreadsheet label/IRM settings and verify whether policy blocks Copilot/AI processing or cross-app reuse. | **No**. The explicit access denial message on sensitive HR data is consistent with policy/label or permission enforcement. |
| 4 | Sales rep: Copilot in Teams can’t find a client contract that was shared with her via a guest link from another org. | 1) guest/external sharing limitation 2) permissions/access boundary 3) sensitivity label restriction 4) data indexing lag 5) license/client prerequisite issue 6) genuine Copilot fault | Verify the contract is accessed through external guest link context (cross-tenant) and not present in tenant-owned indexed content. | **No**. Cross-tenant guest-link scenarios commonly limit what Copilot can ground on in the home tenant context. |
| 5 | IT admin: Copilot suddenly stopped working for the whole Finance team this morning, was fine yesterday. | 1) license/client prerequisite issue 2) permissions/access boundary 3) data indexing lag 4) sensitivity label restriction 5) guest/external sharing limitation 6) genuine Copilot fault | Check one affected user’s Copilot license/service plan status in M365 admin (enabled/removed/suspended). | **Unclear**. Team-wide sudden failure is usually tenant config/licensing/client change first; only consider platform fault after admin checks and service health review. |
| 6 | Manager: Copilot found and summarised a file I don’t remember ever opening, from a folder I forgot I had access to. | 1) permissions/access boundary 2) data indexing lag 3) sensitivity label restriction 4) license/client prerequisite issue 5) guest/external sharing limitation 6) genuine Copilot fault | Validate the manager’s effective permissions on that folder/file (SharePoint/OneDrive “Manage Access”). | **No**. This behavior matches Copilot grounding on content the user is authorized to access, even if they forgot that access existed. |
| 7 | Analyst: Copilot gives generic answers, doesn’t seem to use any of our internal SharePoint content at all. | 1) license/client prerequisite issue 2) permissions/access boundary 3) data indexing lag 4) sensitivity label restriction 5) guest/external sharing limitation 6) genuine Copilot fault | Confirm the analyst is signed into a supported M365 client/account with Copilot license active (correct tenant, correct app build). | **No**. Generic outputs across all internal content usually indicate enablement/client context issues before true Copilot defects. |
| 8 | Executive assistant: Copilot in Outlook can’t see a shared mailbox’s calendar that I manage on behalf of my director. | 1) permissions/access boundary 2) license/client prerequisite issue 3) guest/external sharing limitation 4) sensitivity label restriction 5) data indexing lag 6) genuine Copilot fault | Verify delegate/shared mailbox calendar permissions and whether Copilot supports grounding on that delegated mailbox context in the current client flow. | **Unclear**. Shared/delegate mailbox scope is commonly constrained by access model and feature support boundaries; confirm support matrix before calling it a bug. |

## Triage principle applied

Defaulted to non-Copilot causes first. “Genuine Copilot fault” is ranked last in each case and should only be considered after access, policy, licensing/client, external-sharing, and indexing checks are ruled out.
