# Legal Copilot Support Tickets: End-User Communications

Date: 2026-08-12
Audience: End users reporting Copilot issues

## 1) Paralegal - Copilot cannot summarise client NDA in SharePoint

Plain English explanation:
Copilot is most likely being blocked because it does not have confirmed access to that NDA. Hearing about a folder or seeing it mentioned does not always mean you have permission to use the files inside it.

Next possible steps:
1. We will check whether you have direct access to the NDA file or its folder in SharePoint.
2. We will confirm whether the document has any protection or sensitivity settings that limit Copilot use.
3. If access looks correct, we will re-test after checking whether the file is fully available to Copilot.

What you can do now:
Open the file directly in SharePoint if possible and send IT the exact file link and error message.

## 2) New associate - Copilot in Outlook cannot find case emails

Plain English explanation:
Because your account is new, Copilot may not have finished preparing and indexing your mailbox content yet.

Next possible steps:
1. We will confirm when your account and Copilot license were enabled.
2. We will check that Outlook is signed into the correct work account.
3. We will re-test after enough time has passed for mailbox indexing.

What you can do now:
Stay signed into your work Outlook account and try the prompt again later today.

## 3) Partner - Copilot summarised a draft settlement from another matter

Plain English explanation:
This usually means you already have access to that folder or document, even if you were not aware of it. Copilot can use content you are permitted to open.

Next possible steps:
1. We will check your current access to the source folder and document library.
2. We will confirm whether that access was intentionally granted.
3. If the access is not appropriate, we will ask the document owner to review and remove it.

What you can do now:
Tell IT whether you believe access to that matter should be removed so we can raise an access review quickly.

## 4) Legal ops manager - entire Legal team lost Copilot access this morning

Plain English explanation:
When a whole team loses access at the same time, the cause is usually a licensing, service-plan, or client setup issue rather than something any one person did.

Next possible steps:
1. We will check Copilot license and service-plan status for affected users.
2. We will review any recent tenant, policy, or client configuration changes.
3. We will check Microsoft 365 service health and escalate only if those checks do not explain the issue.

What you can do now:
Send IT a short list of affected users, the first time the issue was noticed, and which apps are failing.

## 5) Contract specialist - Copilot gives vague answers on contract templates

Plain English explanation:
Copilot may not be pulling from the contract library properly yet. This can happen if the documents are not fully indexed, recently changed, or not available in the way Copilot expects.

Next possible steps:
1. We will test with one known template from the library.
2. We will check whether that document is searchable and available to you in SharePoint.
3. We will confirm whether any library settings or protection rules are limiting Copilot retrieval.

What you can do now:
Send IT one example template link and the exact prompt you used so we can test the same scenario.

## Closing note for end users

Most Copilot issues are caused by access, setup, policy, or indexing checks rather than a product defect. We will work through those checks first and keep you updated on the next action.
