# L1 Help Article: AI Helper Showed a File You Did Not Expect

v 1.0, 14/08/2026, status : Draft

If the AI helper shows a file you did not expect to see, follow these safe steps:

1. Stop using that conversation and do not open the file again.
2. Start a new conversation and continue only with files you know are yours.
3. If possible, sign out of your work app and sign back in once.
4. Wait for the IT help desk update before trying the same request again.

Your data is safe. Reporting this quickly helps us check who can view which files and protect private work information.

Please include these details in your support request:
- Your full name
- Team name
- Time it happened
- Which app you were using (for example, Word, Teams, or Outlook)
- The exact question you asked the AI helper
- The file name or folder name shown (if visible)
- A picture of your screen, if you can provide one

Contact the IT help desk if the AI helper shows content you do not expect, or if this happens again after you sign out and sign back in.
